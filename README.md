# DibiTech React

DibiTech React adalah proyek website katalog produk digital yang dikembangkan menggunakan **React.js** dan **Tailwind CSS**. Proyek ini dibuat sebagai bagian dari assignment pembelajaran Full Stack Web Development dengan menerapkan konsep React Components, Props, State, dan Event Handling.

Website ini menampilkan berbagai produk digital seperti AI Tools, UI Kit, Template, dan Assets dengan tampilan yang responsif dan interaktif.

## 🚀 Features

- **Responsive Design** — Tampilan website menyesuaikan ukuran layar desktop, tablet, dan mobile.
- **Product Catalog** — Menampilkan daftar produk digital dalam bentuk card.
- **Category Filter** — Memudahkan pengguna mencari produk berdasarkan kategori.
- **Product Search** — Memungkinkan pengguna mencari produk berdasarkan nama atau kategori.
- **Reusable Components** — Menggunakan komponen React agar kode lebih terstruktur dan mudah dikembangkan.

## ⚙️ Installation & Setup

Ikuti langkah-langkah berikut untuk menjalankan proyek secara lokal.

**1. Clone Repository**

```bash
git clone URL_REPOSITORY_KAMU
```

**2. Masuk ke Folder Proyek**

```bash
cd dibitech-react
```

**3. Install Dependencies**

```bash
npm install
```

**4. Jalankan Development Server**

```bash
npm run dev
```

**5. Buka Website**

Buka alamat lokal yang muncul di terminal, biasanya:

```text
http://localhost:5173
```

## 📚 Learning Objectives

Melalui proyek ini, beberapa konsep React yang dipelajari dan diterapkan meliputi:

- Membuat dan menggunakan React Components.
- Mengirim data antar-komponen menggunakan Props.
- Mengelola data menggunakan State (`useState`).
- Menerapkan Event Handling seperti `onClick` dan `onChange`.
- Menampilkan data menggunakan `.map()`.
- Melakukan pencarian dan penyaringan data menggunakan `.filter()`.
- Menerapkan responsive design menggunakan Tailwind CSS.
